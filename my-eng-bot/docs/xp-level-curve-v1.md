# XP level curve v1

Канон: [`lib/levelCurve.ts`](../lib/levelCurve.ts). Подключение: [`lib/rewardsState.ts`](../lib/rewardsState.ts) (`calculateLevel`).

## Инвариант

Этот документ меняет **только** преобразование `totalXP → level / currentLevelXP / xpToNextLevel`.

Начисление XP не менялось:

- урок: `resolveGlobalLessonXpDelta` / core+combo (max 170, anti-farm vs `bestTotalXp`)
- практика: слоты + daily cap 70
- streak: +10 / +15 / +20 раз в день
- события режимов: как в `rewardsEvents`

## Формула

Полоска уровня L (L ≥ 1):

```text
xpToNext(L) = 80 + 20·L
```

Кумулятив, чтобы стать уровнем N:

```text
T(N) = (N − 1)·(80 + 10·N) = 10N² + 70N − 80
```

Обратный расчёт (с проверкой соседних порогов):

```text
L ≈ floor((-70 + √(8100 + 40·XP)) / 20)
```

`totalXP` — источник истины. Derived-поля пересчитываются на load и award. Рескейл `totalXP` и dual-curve не используются.

Дневные ориентиры на 120 дней:

- средний: `120 × (125+70+20) = 25800` → L47
- идеальный: `120 × (170+70+20) = 31200` → L52

Уровень нельзя однозначно вывести из числа уроков: практика и streak зависят от активных дней.
