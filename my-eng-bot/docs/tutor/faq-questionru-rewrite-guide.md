# FAQ questionRu rewrite — руководство (Engvo)

Правила приняты при F2 Round1 (A1 micro v4). Использовать во всех следующих батчах (grammar F2, F3…).

## Цикл работы

1. Агент даёт **варианты** таблицей `id | было | предлагаю` — без кода.
2. Человек **OK** или правки по строкам.
3. Только после OK — правки `data/*.ts` + explain stubs `pending`.
4. В конце раунда агент пишет в `docs/tutor/`: **что осталось** + COPY-handoff. Человек промпт не дублирует.

Размер раунда: ориентир **~75 id** за OK (Round1 micro = 48 целиком — исключение).

## Модель записи

- `id` — стабильный ключ, **не сливать** дубли уровней.
- `questionRu` — единственный display-эталон (TutorIdleMenu / MyPlan prefill).
- Старый `questionRu` → в **начало** `aliases` (match старых формулировок).
- Data-файлы = SoT; **не** запускать `scripts/generateLocalFaq.mjs`.
- Stubs: `status: pending` — **не** в lookup / GOLDEN_PATH.
- Explain — только после фразы «можно генерировать Explain».

## Правила формулировки questionRu

### 1. EN-фраза обязательна

В chip должна остаться исходная английская форма в кавычках «…».  
Русский смысл — вокруг неё, **не вместо** неё.

### 2. Anti-spoiler (самое важное)

Запрещено, если ответ Explain уже содержится в вопросе:

- плохо: `Как спросить, кем работает: «What’s your job?»?` — EN и есть ответ;
- плохо: `Как сказать X: «EN»?`, когда «EN» = единственный ответ на «как сказать X».

Норма — вопрос оставляет зазор для Explain:

- **В какой ситуации** говорят «EN»?
- **Когда** …, почему говорят «EN»?
- **Когда** «A», а когда «B»?
- **Чем** «A» отличается от «B»?
- **Что значит** «EN»? (если без ситуации всё равно ясно)

Не усложнять: ситуация → форма. Без тяжёлой теории в chip.

Проверка: «что должен ответить репетитор?» — если ответ уже в chip целиком, переписать.

### 3. Детский / живой смысл

Думай как в реальной речи ученика:

- сначала ситуация или русский ход («у меня есть», «дорога», «не хотели ли бы вы»);
- потом английская форма как объект разбора;
- мета («полезная фраза», «в разных ситуациях») — в Explain, не в chip.
- **Не писать BrE / AmE** в chip — только «британское» / «американское».
- Не тащить в chip редкий жаргон вроде `amn’t` — это материал Explain, не вопроса.

### 4. Шаблоны по классу

| Класс | Шаблон |
|---|---|
| vs / две формы | Чем «A» отличается от «B»? |
| ≠ / выбор | Когда «A», а когда «B»? |
| ритуал / момент | Когда говорят «…»? |
| голая форма / смысл | Что значит «…»? / Почему говорят «…»? |
| calque RU→EN | Почему «EN», а не как по-русски «…» дословно? |
| Continuous vs общее | Почему Continuous, если … вообще, а не только сейчас? |
| вежливость / норма | Почему вежливо … «EN»? |

«Как спросить: «EN»?» из F1 — только если chip **не** раскрывает весь ответ (редко; чаще лучше Когда/Почему).

### 5. Genre mistag

Если запись tagged `grammar`, но по смыслу phrase/ритуал — при rewrite ставить `genre: "phrase"` (как Round1 micro / F1 functional).  
`pickIdleFaq` берёт только `idleEligible && (grammar|contrast)` — phrase с `idleEligible: false` в idle не попадёт.

### 6. Дубли

Близкие functional/micro id **не сливать**. Различать формулировкой (напр. `No, thanks` vs `No, thank you`; `See you!` vs `See you tomorrow!`).
